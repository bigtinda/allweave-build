# M4 遗留问题

## M4-01 gateway 仍在 server

- 状态：in-progress
- 现象：`PiAiGateway` 已迁到 `packages/kernel-adapters`；`ModelRuntime`、auth、model list 仍在 `apps/server/src/providers.ts`。
- 已完成：`PiAiGateway`、`NativeModelRuntime`、模型 DTO 映射进入 `packages/kernel-adapters/src/pi-ai/gateway.ts`；server 只保留类型引用。
- 剩余：ProviderManager/auth 迁移，server 不再直接 import `ModelRuntime`。
- 验收：kernel/adapters 边界稳定，server provider 只依赖 `ModelGateway`。

## M4-02 SettingsManager / ResourceLoader 未迁移

- 状态：open
- 现象：settings、skills、prompts、package 资源仍由 coding-agent 加载。
- 修复条件：context builder 能消费统一资源 DTO。
- 修复动作：settings 版本化 + 旧字段读取；资源 provider 接口化。
- 验收：原生引擎不依赖 coding-agent 的 settings/resource loader。

## M4-03 原生历史不保存 tool 结果

- 状态：resolved（2026-11-04）
- 现象：`NativeAgentRuntime` 只把 user/assistant 写回 `this.messages`；下一轮丢失 tool result，模型会重复调用工具。
- 修复：`ChatMessage` 增加 `toolCalls`/`toolResults`；`nativeHistory` 还原 assistant + tool 消息；最终 assistant 持久化本轮工具调用与结果。
- 验收：`apps/server/test/native-runtime.test.ts` 新增两轮测试，第二次请求包含 `toolResult` 与 `call-ls`，4/4 通过。

## M4-04 token 估算未校准

- 状态：in-progress
- 现象：`context/budget.ts` 使用 CJK 1 字符≈1 token、其他 4 字符≈1 token。
- 已完成：`buildContext` 支持 `estimateScale`；原生引擎用 provider usage（input+cache）做会话内 EMA（0.5–2.0），下一轮生效。
- 剩余：系数未持久化，重启回到 1；未用 100k 中英文真实样本验证 <10% 误差。
- 验收：中文/英文估算误差 <10%，不 overflow。

## M4-05 压缩事件未进入协议

- 状态：resolved（2026-11-04）
- 现象：`context.compacted` 只在内核计数，Web/事件流看不到压缩发生。
- 修复：`EventType` 增加 `context.compacted`；`SessionEvent`/`AdaptedEvent` 增加 `compaction {dropped, estimatedTokens}`；原生引擎在压缩发生时发事件，投影写入 activity。
- 验收：`packages/protocol/test/reducer.test.ts` 新增压缩事件测试，5/5 通过。

## M4-06 prompt cache 未验证

- 状态：open
- 现象：系统前缀已稳定排序，但没有 cache read/write 指标断言。
- 修复条件：真实 provider 或可记录 cache 的 faux provider。
- 修复动作：基准记录 cacheRead/cacheWrite，压缩前后对比。
- 验收：正常对话 cache read > 0；压缩不使主前缀失效。

## M4-07 plan 提示仍在 coordinator

- 状态：resolved（原生引擎；Pi 路径保留兼容）
- 现象：`SessionCoordinator.promptForAccessMode` 仍拼接计划模式提示。
- 修复：`AgentRuntime.handlesPlanMode` 标记引擎自行处理；`NativeAgentRuntime` 在 system prompt 追加 Plan mode 段，coordinator 对原生引擎跳过前缀。
- 验收：`native-runtime.test.ts` 计划模式测试 4/4 通过；Pi 路径行为不变。
