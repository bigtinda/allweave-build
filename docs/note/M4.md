# M4 遗留问题

## M4-01 gateway 仍在 server

- 状态：open
- 现象：`PiAiGateway` 和 `ModelRuntime` 仍在 `apps/server/src/sessions/native-runtime.ts` / `providers.ts`。
- 修复条件：`packages/kernel-adapters` 建立，pi-ai 依赖集中到 adapter。
- 修复动作：迁移 gateway、auth、model list；server 只依赖 `ModelGateway`。
- 验收：kernel 无 pi-ai import；server 不再直接 import `ModelRuntime`。

## M4-02 SettingsManager / ResourceLoader 未迁移

- 状态：open
- 现象：settings、skills、prompts、package 资源仍由 coding-agent 加载。
- 修复条件：context builder 能消费统一资源 DTO。
- 修复动作：settings 版本化 + 旧字段读取；资源 provider 接口化。
- 验收：原生引擎不依赖 coding-agent 的 settings/resource loader。

## M4-03 原生历史不保存 tool 结果

- 状态：open（高优先级）
- 现象：`NativeAgentRuntime` 只把 user/assistant 写回 `this.messages`；下一轮丢失 tool result，模型会重复调用工具。
- 修复条件：协议允许 tool 消息或可重建的 tool 结果序列。
- 修复动作：扩展 `ChatMessage`/内部事件，持久化 tool call/result；或每轮从 event store 重建。
- 验收：两轮工具调用上下文与 PiEngine 一致。

## M4-04 token 估算未校准

- 状态：open
- 现象：`context/budget.ts` 使用 CJK 1 字符≈1 token、其他 4 字符≈1 token；未用 provider usage 校准。
- 修复条件：M4 真实 provider 测试可用。
- 修复动作：按 provider/model 记录 usage EMA，修正系数；补 100k 中英文误差测试。
- 验收：中文/英文估算误差 <10%，不 overflow。

## M4-05 压缩事件未进入协议

- 状态：open
- 现象：`context.compacted` 只在内核计数，Web/事件流看不到压缩发生。
- 修复条件：协议事件版本升级。
- 修复动作：增加事件类型与 UI 提示；保留 firstKept/摘要元数据。
- 验收：压缩后刷新/重启 UI 仍显示摘要边界。

## M4-06 prompt cache 未验证

- 状态：open
- 现象：系统前缀已稳定排序，但没有 cache read/write 指标断言。
- 修复条件：真实 provider 或可记录 cache 的 faux provider。
- 修复动作：基准记录 cacheRead/cacheWrite，压缩前后对比。
- 验收：正常对话 cache read > 0；压缩不使主前缀失效。

## M4-07 plan 提示仍在 coordinator

- 状态：open
- 现象：`SessionCoordinator.promptForAccessMode` 仍拼接计划模式提示。
- 修复条件：context/policy 统一输入。
- 修复动作：移到 `context/builder` 或 policy 生成 system section。
- 验收：两种引擎提示一致。
