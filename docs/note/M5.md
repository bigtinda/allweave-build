## 已实现

- `packages/kernel/src/extensions`：10 个 hook 类型、顺序执行、失败诊断、重复工具/扩展诊断、`registerTool`、`registerResourceProvider`。
- `runNativeLoop` 接入 `turn_start/context/message_end/tool_call/tool_result/turn_end`；hook 可改写输入、阻断工具、修补结果。
- `NativeAgentRuntime` 合并 builtin + app plugin + extension + MCP + codemode/tool-search tools；插件开发会话限制为 read/write/edit/ls + `plugin_*`。
- `packages/kernel-adapters`：`createMcpNativeTools`、`createMcpManager`、`loadMcpConfig`、`createCodemodeNativeTool`、`bridgeLegacyExtension`。

- MCP OAuth、断线重连、配置热更新未做。
- legacy bridge 未覆盖 UI/command/shortcut。
