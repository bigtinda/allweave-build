# AllWeave Build 工作台界面规范

适用于 `apps/web`，沿用 React、MUI 和原生 CSS。默认主色为克莱因蓝 `#002FA7`；保留用户已有的主题、字体和壁纸选择。

## 共享规则

- 主题颜色由 `theme/personalization.ts` 生成，MUI 控件由 `theme/theme.ts` 配置。
- 工作台布局和状态样式集中在 `workbench.css`，在现有样式之后加载。
- 浅色背景采用白色与暖灰，文字使用石墨色，分隔线使用 `#EAEAEA`。
- 使用已有系统字体；正文 14–15px，辅助信息 12px，页面标题 24px，会话标题 18px。
- 控件圆角 6px，主要面板圆角 10px；使用细边框，不使用面板投影。
- 数值使用等宽数字。代码、路径、快捷键使用等宽字体。
- 主按钮用于新建、发送与确认；次要操作使用文本或描边按钮。
- 关键操作保留可读文字、键盘焦点和可访问名称。桌面收起导航后保留 64px 导航栏，操作目标至少 44px；小屏使用抽屉。
- 状态同时使用文字和色彩：蓝色执行中、浅黄等待确认、浅绿完成、浅红失败。
- 页面切换使用短距离位移与淡入，退出页面隐藏以防止内容重叠。减少动态效果时立即完成切换。
- 长内容只在内容区滚动；输入区保留在底部。滚动条可见，小屏输入区使用两行操作布局。
- 项目侧栏顶部保留搜索；项目区占据中部滚动区域，技能与插件、插件开发、模型与设置固定在底部，主题切换位于最底行。项目区标题旁创建项目；每个项目行的加号只在该项目中新建会话。点击项目名称会选中项目并展开或收起会话，箭头提供同样的折叠操作。默认显示最近 5 个匹配会话，点击“展开其余”查看完整列表；收起侧栏时保留新建项目入口，展开按钮使用 Build 标志。
- 存储会话记录采用卡片，每页 8 个，保留标题跳转、时间、状态、大小及删除确认。
- 输入框下展示会话累计 Token 与缓存命中率，点击查看未缓存输入、输出、缓存读取/写入和估算费用。命中率分母为未缓存输入 + 缓存读取 + 缓存写入；缺失历史数据标为未记录。

## 问题与行为变化

| 原问题 | 实现后的行为 |
| --- | --- |
| 项目与会话创建入口混在一起 | 项目区标题用于新建项目；每个项目标题旁的加号在对应项目中新建会话；点击项目名称可展开或收起会话 |
| 输入框焦点出现嵌套描边 | 对话输入框只显示外层 composer 焦点边框，textarea 不绘制内层 outline |
| 模型目录只能逐页找 | 一级选择供应商，二级选择该供应商的模型；搜索跨供应商筛选，分页仅针对当前供应商 |
| 发送只有图标，权限提示与实际模式无关 | 显示“发送”与“停止”，提示当前权限；请求处理中禁用重复操作 |
| 文件面板打开后隐藏会话状态 | 会话状态与面板开关始终可见；等待审批不显示运行进度 |
| 接口保存错误被弹窗遮住 | 表单内显示校验与服务端错误，失败保留输入，成功返回供应商列表并提示下一步 |
| 调整模型缺少结果反馈 | 成功更新会话并显示已保存提示 |
| 文件保存后缺少反馈 | 显示保存成功和文件路径，继续编辑时清除旧提示 |
| 长内容无法判断可滚动 | 恢复细滚动条，保留代码块、表格和工具输出滚动 |
| 首页无法直接恢复工作 | 增加最近会话和模型配置入口 |
| 页面切换期间旧页面透出 | 退出层透明，当前页短距离淡入 |
| 小侧栏出现时先挤开大侧栏 | 两种侧栏共用宽度容器，在 276px 与 64px 之间连续变化；小侧栏在容器内部淡入，展开时立即隐藏且不可聚焦 |
| 相同模型错误重复提示 | 最新回复已显示错误时，不重复显示同一会话错误；连接错误增加网络与供应商配置指引 |
| 主动停止仍显示执行失败 | 当前会话显示“已停止”和内容保留提示，后端状态及历史数据不变 |
| 工具卡片重复占据聊天正文 | 输入、输出与执行状态仅在工作区“工具”页显示；标签显示数量及执行中提示，审批确认保留 |
| 工具前后回复和推理分散，最终答案难找 | 每次用户任务的连续 AI 消息合并；推理与过程说明集中在一个默认收起的框内，最后回答显示为正文；用户任务靠右并使用浅色背景，AI 回复靠左 |

## 验证

- 界面改动在 1366×768 与 390×844 下检查浅色/深色布局、无横向溢出、键盘焦点与审批状态可读。
- 仓库完整校验使用 `npm run check`；前端边界测试使用 `npm run test --workspace=@pi-console/web`。
- 真实供应商登录、真实聊天和插件安装属于发布前人工验收，依赖本机配置，不在本文记录一次性测试流水。

## Git 管理

工作区增加“Git”页：显示当前分支与未暂存/已暂存文件，点击文件查看文本差异，可展开差异窗口。逐文件暂存、取消暂存后提示结果；提交前列出全部已暂存文件。暂存区或当前分支发生变化后，旧请求会被拒绝。

支持从现有本地分支创建分支、切换本地分支、安全删除本地分支。创建后停留在当前分支；切换要求工作区干净且项目没有正在执行的任务，文件预览有未保存内容时禁用切换。删除需要确认，当前分支、未合并分支及被工作树占用的分支不能删除。

沿用文件访问限制，不预览或暂存私有配置、符号链接；如暂存区包含受保护文件，拒绝提交。项目必须指向仓库根目录。远程同步、历史查看、强制删除及冲突解决界面尚未实现，原有工作树功能保留。

专项测试在临时仓库验证暂存、取消暂存、提交、过期状态拒绝、私有路径限制、创建/切换/删除分支，以及脏工作区与未合并分支保护。真实项目仅验证列表、差异和分支对话框，不暂存、提交或切换当前仓库。
