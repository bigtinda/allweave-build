## 已实现

- `packages/kernel/src/extensions`：10 个 hook 类型、顺序执行、失败诊断、重复工具/扩展诊断、`registerTool`、`registerResourceProvider`。
- `runNativeLoop` 接入 `turn_start/context/message_end/tool_call/tool_result/turn_end`；hook 可改写输入、阻断工具、修补结果。
- `NativeAgentRuntime` 合并 builtin + app plugin + extension tools；插件开发会话限制为 read/write/edit/ls + `plugin_*`。
- app plugin 工具：`plugin_list/validate/install`、`plugin_<id>_{list,create,update,delete}`。
- `packages/kernel-adapters`：`createMcpNativeTools`、`bridgeLegacyExtension`。

## 验收缺口

- 浏览器、codemode、tool-search 未在原生路径可用。
- 没有真实 MCP server / doompi 扩展的端到端测试。
- 扩展热刷新未接原生 runtime。
