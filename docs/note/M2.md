# M2 遗留问题

## M2-01 interrupted 会话不能续跑

- 状态：open
- 现象：server 重启后非 idle 会话标为 `interrupted`，用户只能重新发消息，无法从最后一个完整 turn 继续。
- 位置：`apps/server/src/persistence/event-projector.ts`、`apps/server/src/sessions/coordinator.ts`。
- 当前规避：保留历史消息，工具未完成标记 failed。
- 修复条件：M4 上下文/事件格式稳定，能定义“最后安全 turn”。
- 修复动作：增加显式 resume 命令，从最后一个 `message.completed` 或作答边界继续；不自动重放工具。
- 验收：中断后恢复不重复已执行写操作。

## M2-02 原生引擎不支持分支

- 状态：resolved（M6）
- 历史现象：`NativeAgentRuntime.navigate()` 曾返回 409。
- 结果：已按消息截断内部历史并返回 `toolIds`/usage。
- 位置：`apps/server/src/sessions/native-runtime.ts`。
- 当前规避：原生引擎只用于新短会话；分支会话走 PiEngine。
- 修复条件：M4 事件/快照支持 branch 边界。
- 修复动作：native 分支或按会话强制 PiEngine。
- 验收：分支操作在两种引擎行为一致。

## M2-03 引擎选择是全局环境变量

- 状态：resolved（M6；PiEngine 已删除，选择开关不再需要）
- 现象：`KERNEL_ENGINE=native` 全局开关，不能按会话灰度/回退。
- 位置：`apps/server/src/sessions/pi-runtime.adapter.ts`。
- 修复条件：M4 原生引擎覆盖长会话。
- 修复动作：会话级 engine 字段或灰度比例；保留 Pi 回退。
- 验收：单会话可切换且不影响其他会话。

## M2-04 审批超时没有独立计时器

- 状态：open
- 现象：审批超时依赖 `ToolAuthorization` 的 5 分钟 Promise 计时，server 进程退出即丢失。
- 位置：`apps/server/src/sessions/tool-authorization.ts`。
- 当前规避：启动时 `expireApprovals`。
- 修复条件：M4 审批事件持久化稳定。
- 修复动作：内核或 store 驱动过期，UI 可恢复。
- 验收：重启后审批状态一致，无悬挂 running。
