## 已实现

- 生产默认：无测试注入、无远程、`KERNEL_EXTENSIONS!=legacy`、`KERNEL_ENGINE!=pi` 时，所有新会话与恢复会话走 `NativeAgentRuntime`。
- PiEngine 仅在 `KERNEL_ENGINE=pi`、`KERNEL_EXTENSIONS=legacy` 或测试注入 `createSession` 时使用。
