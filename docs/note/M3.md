# M3 遗留问题

## M3-01 工具只顺序执行

- 状态：resolved
- 现象：`runNativeLoop` 对每个 tool call 串行 `await`，没有并行只读批次。
- 位置：`packages/kernel/src/engine/loop.ts`。
- 修复条件：无，当前可修。
- 修复动作：连续只读工具 `Promise.all`；含写工具的批次回退串行。
- 验收：两项只读工具总耗时接近单项；事件仍成对且结果顺序稳定。
- 结果：`packages/kernel/test/engine.test.ts` 覆盖两项 60 ms 只读工具，实测 <110 ms；提交见 M3 完善提交。

## M3-02 没有 retry/backoff

- 状态：resolved
- 现象：provider 429/5xx/网络错误直接冒泡，整轮失败。
- 位置：`packages/kernel/src/engine/loop.ts`。
- 修复条件：无，当前可修。
- 修复动作：新增 `retry.ts`，分类可重试错误，指数退避 + jitter；已输出增量后不重试，避免重复文本。
- 验收：429/500 重试成功；400/401 不重试；abort 立即停止。
- 结果：`packages/kernel/src/engine/retry.ts`；已输出增量后不重试；测试覆盖 rate limit 重试。

- 结果：`packages/kernel/src/engine/policy.ts`；`native-runtime.ts` 只做审批转发。
